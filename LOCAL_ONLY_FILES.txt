# LOCAL-ONLY FILES — develop branch only
# =============================================
# These files exist ONLY on develop for local Docker development.
# They must NEVER be merged to main. CI and deploy will fail if they are.
#
# WHY: Local Docker dev needs an nginx proxy (like production) to avoid
# per-component apiUrl() changes. These files set up that proxy.
# With nginx proxy, frontend code uses the SAME relative URLs on both
# branches — no apiUrl() rewrites needed.
#
# HOW TO USE:
#   1. Before any merge/PR to main, run: bash scripts/prepare-merge.sh
#   2. Merge to main, push, deploy
#   3. Switch back to develop, merge main
#   4. Run: bash scripts/apply-local-only.sh
#
# FILE FORMAT: one relative path per line. Lines starting with # are comments.
# Empty lines are ignored.
